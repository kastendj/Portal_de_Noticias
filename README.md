# Portal de Notícias — Formulários

Projeto da disciplina **Desenvolvimento Web I** — IFC Campus Araquari.

## Estrutura

- `index.html` — notícias + filtro (`method="get"`)
- `hobbies.html` — sugestão de temas/hobbies
- `perfil.html` — perfil do estudante
- `contato.html` — contato ampliado
- `noticias/noticia-html.html`
- `noticias/noticia-banco-dados.html`

## Recursos praticados

- Estrutura de formulários HTML
- Tipos de `input`, `select`, `textarea`, `checkbox`, `radio`
- `label` + `for`/`id`, `name`, `value`, `required`, `minlength`, `maxlength`
- `method="get"` (filtro) e `method="post"` (avaliação/sugestão/contato)
- `aria-current="page"` no menu
- Flexbox, variáveis CSS, foco visível e responsividade
